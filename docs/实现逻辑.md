## 项目概览

WhereToGO 是一个以桌面端为主的互动记忆站点，前端使用 React + Vite，3D/地球交互使用 Three.js / React Three Fiber 与 Cesium，数据与登录由 Supabase 提供，部署在 Vercel。

这套项目当前是“前端为主 + BaaS 后端”：没有自建 Node/Java 等服务端，后端能力全部来自 Supabase（Auth、Postgres、Storage、RLS）。

## 技术栈与框架

### 前端

- React 18 + Vite 5
- Framer Motion：页面动效与弹窗动效
- Three.js / @react-three/fiber / drei：关键词宇宙、行星/星空等 3D
- Cesium：地球/地图交互
- Recharts：能量曲线/可视化

### 后端（Supabase）

- Supabase Auth：邮箱+密码登录、邀请制
- Supabase Postgres：业务数据（城市、照片、Firsts、Letters、关键词能量等）
- Supabase Storage：图片等媒体（Firsts 已在用；城市照片待迁移）
- RLS（Row Level Security）：限制只有登录成员才能读写

### 部署

- Vercel：静态前端托管、环境变量、自动构建发布

## 页面“设计”是怎么写的？

主要是通过 React 组件（`.jsx` 文件）来实现页面结构与交互：

- 组件渲染：JSX（在 `.jsx` 文件里写）
- 动效：Framer Motion（也写在 `.jsx`）
- 样式：当前项目大量使用“组件内联 style 对象”（JS 里写 CSS），同时也有少量 CSS 文件（如 `src/style.css`、letters 模块的 css）

所以你改 UI/文案，通常直接改对应的 `.jsx` 文件就能生效。

## 登录与昵称逻辑

### 入口与门禁

- [App.jsx](file:///Users/lld/Documents/trae_projects/ToWhere/ToWhereOnline-main/src/App.jsx)：
  - 未登录：显示 PublicLanding（欢迎页）+ LoginModal（邮箱密码登录）
  - 登录后：进入 AuthenticatedApp（主应用）
  - 邀请/重置链接：URL hash 里带 `type=invite/recovery` 时弹出 SetPasswordModal

### 会话与昵称

- [AuthContext.jsx](file:///Users/lld/Documents/trae_projects/ToWhere/ToWhereOnline-main/src/context/AuthContext.jsx)：
  - 维护 Supabase session
  - 从 `profiles` 表读取 `display_name`
  - 提供 `updateDisplayName()` 用于更新昵称
- [AccountBadge.jsx](file:///Users/lld/Documents/trae_projects/ToWhere/ToWhereOnline-main/src/components/AccountBadge.jsx)：
  - 默认显示昵称（优先 profiles.display\_name，其次 user\_metadata.display\_name，再次邮箱前缀）
  - 点击昵称可编辑并保存到 profiles
  - 角落提供退出按钮
